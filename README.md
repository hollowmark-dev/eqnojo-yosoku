# イコノイジョイ推し予測

実在しない人物の顔を見比べて、好みの傾向を推定し、＝LOVE・≠ME・≒JOY のメンバーから傾向の近い3人をさがすツールです。

**サイト:** https://hollowmark-dev.github.io/eqnojo-yosoku/

## 大事なこと

- 表示される顔は、すべて画像生成モデル（RealVisXL V4.0）で作った**実在しない人物の顔**です。
- メンバーの写真は、モデルの学習にも顔の生成にも、このリポジトリにも一切使用していません。結果画面には、氏名・グループ名・公式ページへのリンクだけを表示します。
- 個人が制作した非公式のファンサイトです。＝LOVE・≠ME・≒JOY の運営・事務所とは関係ありません。
- 権利者の方からご要請があれば、ただちに公開を停止します。ご連絡は X: @nooton123 のDMまで。
